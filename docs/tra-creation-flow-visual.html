📋 Het Proces Stap voor Stap
1
👤 Jij Opent de Website
Je gaat naar de website en klikt op "Nieuw TRA aanmaken"
Wat gebeurt? De website laadt en toont je een formulier
↓
2
✏️ Stap 1: Basis Informatie
Je vult in: wat is de taak, wat gaat je analyseren, wat is de titel?
Je moet invullen: Titel van je analyse, beschrijving, welk project hoort dit bij
↓
3
⚠️ Stap 2: Welke Gevaren?
Je beschrijft alle mogelijke gevaren voor deze taak
Bijvoorbeeld: Elektrocutie risico, val risico, brand risico, enzovoort
↓
4
👥 Stap 3: Wie Doet Dit?
Je selecteert welke teamleden betrokken zijn bij deze taak
Minstens: 1 teamlid moet geselecteerd worden
↓
5
🔍 Stap 4: Controle
De website laat alles nog een keer zien, je controleert of alles goed is
Hier kan je: Nog iets aanpassen, of doorgaan naar stap 6
↓
✋ TOT HIER GEBEURT ALLES OP JE COMPUTER ✋
6
📤 Je Verzendt Alles
Je klikt op "Opslaan" en alles gaat naar de server
Achter de schermen: Alles wat je hebt ingevuld wordt naar de server verzonden
↓
🖥️ VANAF NU WERKT DE SERVER HET AF 🖥️
7
🔐 Server Checkt: Ben Jij Ingelogd?
De server controleert of je echt bent wie je zegt dat je bent
Wat gebeurt? De server kijkt naar je inloggegevens
↓
8
✅ Server Checkt: Is Het Goed Ingevuld?
De server controleert of alles wat je hebt ingevuld logisch is
Bijvoorbeeld: Is er een titel? Hoort het project echt bij jouw bedrijf?
↓
9
💳 Server Checkt: Mag Dit Nog?
De server controleert of je bedrijf nog meer TRA's mag aanmaken
Bijvoorbeeld: Sommige abonnementen hebben limieten: je mag maar 5 analyses per maand maken
↓
10
💾 Server Slaat Het Op
Als alles goed is, slaat de server alles op in de database
Wat wordt opgeslagen? Je titel, beschrijving, alle gevaren, teamleden, alles
↓
11
📥 Server Geeft Bericht Terug
De server zegt: "Prima! Je analyse is opgeslagen!"
Je computer ontvangt: Een berichtje dat alles gelukt is
↓
🖥️ TERUG NAAR JE COMPUTER 🖥️
12
🎉 Website Brengt Je Naar Je Analyse
De website laadt automatisch de pagina van je nieuwe analyse
✓ KLAAR! Je TRA is aangemaakt!

💡 Samengevat

Stap 1-5: Jij vult op je computer een formulier in met 4 schermen. Jij bepaalt wat je analyseert.

Stap 6: Je drukt op "Opslaan" en alles gaat naar de server.

Stap 7-10: De server controleert of alles goed is, en slaat het op in de database.

Stap 11-12: De server zegt dat het gelukt is, en je website brengt je naar je nieuwe analyse. ✓ Klaar!
