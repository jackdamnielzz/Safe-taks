## Data Structure

### Signature Data Model

```typescript
interface LMRAStep8_Signature {
  signerId: string;              // Unique ID: "sig-{timestamp}"
  signerName?: string;            // Display name
  signatureType: SignatureType;   // "image" | "typed" | "consent_checkbox"
  signatureData: string;          // Base64 PNG data URL
  signedAt: Timestamp | Date;     // Signature timestamp
  role?: string;                  // User role
  notes?: string;                 // Optional notes
}
```

### Storage Format

Signatures are stored as **base64 data URLs**:
```
data:image/png;base64,iVBORw0KGgoAAAANSUhEUg...
```

**Advantages**:
- ✅ No external storage needed (stored in Firestore)
- ✅ Immediate availability (no upload delay)
- ✅ Works offline
- ✅ Simple to display (`<img src={signatureData} />`)

**Considerations**:
- Base64 increases size by ~33%
- Typical signature: 5-15 KB (acceptable for Firestore)
- Max Firestore document: 1 MB (can store 50-100 signatures)

### Responsive Sizing

```typescript
useEffect(() => {
  const updateSize = () => {
    const container = document.getElementById("signature-container");
    if (container) {
      const width = Math.min(container.clientWidth - 32, 600);
      const height = Math.min(width * 0.4, 250);
      setCanvasSize({ width, height });
    }
  };
  
  updateSize();
  window.addEventListener("resize", updateSize);
  return () => window.removeEventListener("resize", updateSize);
}, []);
```

3. Responsive canvas sizing improves mobile UX
