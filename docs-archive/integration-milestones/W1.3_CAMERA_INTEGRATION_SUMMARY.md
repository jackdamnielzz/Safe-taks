### 3. Photo Upload Service (`web/src/lib/photoUpload.ts`)
**Purpose**: Handles photo compression and upload to Firebase Storage

**Features**:
- ✅ Image compression using `browser-image-compression`
- ✅ Automatic thumbnail generation
- ✅ Upload to Firebase Storage with progress tracking
- ✅ Automatic retry with exponential backoff
- ✅ Firestore metadata storage
- ✅ Offline queue management
- ✅ Multiple concurrent uploads

**Compression Settings**:
- **Main Image**: Max 2MB, 2048px max dimension, 80% quality
- **Thumbnail**: Max 100KB, 400px max dimension, 70% quality
- **Format**: JPEG for optimal compression

**Key Methods**:
- `compressImage()` - Compress image before upload
- `generateThumbnail()` - Create thumbnail version
- `uploadPhoto()` - Upload to Firebase Storage
- `uploadPhotoWithRetry()` - Upload with automatic retry
- `syncPendingPhotos()` - Sync all pending photos
- `queueUpload()` - Add photo to upload queue

**Upload Flow**:
1. Compress main image (40-60% size reduction)
2. Generate thumbnail
3. Upload main image to `lmras/{lmraId}/photos/{photoId}.jpg`
4. Upload thumbnail to `lmras/{lmraId}/photos/thumbnails/{photoId}_thumb.jpg`
5. Save metadata to Firestore `lmraPhotos` collection
6. Update local storage with Firebase URLs

### Performance Optimizations

- **Lazy Loading**: Photos loaded on demand
- **Offline Support**: Photos stored locally until uploaded
- **Progressive Upload**: Queue system for multiple photos
