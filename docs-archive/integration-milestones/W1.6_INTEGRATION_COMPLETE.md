## 📝 Important Notes

### Auth Context Pattern
The project uses `useAuth()` from `@/components/AuthProvider`:
```typescript
const { user, userProfile } = useAuth();
// user.uid - Firebase user ID
// user.email - User email
// userProfile.firstName, lastName - User name
// userProfile.role - User role (admin, safety_manager, supervisor, field_worker)
```

### Stop-Work Button Visibility
The button only appears when:
- LMRA has been created (has an ID)
- User is executing LMRA workflow
- Fixed position: bottom-right corner (z-index: 50)

### Offline Behavior
- Alerts queue in localStorage if offline
- Auto-sync when network reconnects
- Retry logic: max 3 attempts with exponential backoff
- User sees "Melding wordt verzonden zodra u online bent" message
