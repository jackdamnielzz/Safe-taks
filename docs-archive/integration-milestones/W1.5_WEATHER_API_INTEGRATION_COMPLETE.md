## 🔒 Enhanced Safety Rules

### Blocking Conditions (Work MUST Stop)

1. **Extreme Wind**: > 60 km/h (16.7 m/s)
   - Blocks all outdoor work
   - Red banner with stop icon

2. **Thunderstorm**: Any thunderstorm detected
   - Blocks all outdoor work immediately
   - Lightning safety protocol

3. **Extreme Temperature**:
   - > 40°C: Heat exhaustion risk
   - < -15°C: Hypothermia risk

4. **Extreme Severity**: Weather severity = "extreme"
   - Automatic work stoppage

### Warning Conditions (Caution Required)

1. **High Wind**: > 40 km/h (11 m/s)
   - Yellow warning banner
   - Extra precautions required

2. **Temperature Warnings**:
   - 35-40°C: Extra breaks and hydration
   - -10 to -15°C: Extra protective clothing

3. **Severe Weather**: Severity = "severe"
   - Heavy rain, snow, or poor visibility

### Work-Type Specific Limits

#### Work at Height
- Wind limit: 60 km/h (8 m/s) - **stricter than general**
- Extra warnings for elevated work

#### Electrical Work
- Wind limit: 40 km/h (11 m/s)
- **No rain allowed** - blocks work if precipitation detected
- Extra caution for wet conditions

#### Confined Space
- Temperature: 35°C max, -5°C min - **stricter than general**
- Ventilation considerations

#### Hot Work (Welding, Cutting)
- Wind limit: 54 km/h (15 m/s)
- **No rain allowed** - fire safety
- Spark control in wind

## 📊 Data Flow

### 1. LMRA Execution Flow
```
User completes Step 2 (Location Verification)
  ↓
GPS coordinates saved to LMRA.step2
  ↓
User navigates to Step 3 (Weather Conditions)
  ↓
Component auto-fetches weather
  ↓
WeatherService.getWeatherWithCache(lat, lon)
  ↓
Check localStorage cache (1-hour TTL)
  ↓
If cached & fresh: Return cached data
If not: Fetch from OpenWeather API
  ↓
Calculate severity and safety
  ↓
Display weather + warnings/blocking
```

### 2. Safety Check Flow
```
Weather data received
  ↓
Determine work type from TRA
  ↓
Apply work-type specific limits
  ↓
Check blocking conditions:
  - Extreme wind (>60 km/h)
  - Thunderstorm
  - Extreme temperature
  - Extreme severity
  ↓
If blocking: Show red banner, prevent continuation
  ↓
Check warning conditions:
  - High wind
  - Temperature extremes
  - Rain (for electrical/hot work)
  - Severe weather
  ↓
If warnings: Show yellow banner, allow with caution
  ↓
Return safety assessment
```

## 🔧 Configuration

### Environment Variables

#### Development (`.env.local`)
```bash
NEXT_PUBLIC_OPENWEATHER_API_KEY=your_api_key_here
```

#### Preview (`.env.preview`)
```bash
NEXT_PUBLIC_OPENWEATHER_API_KEY=your_preview_api_key_here
```

#### Production (Vercel)
```bash
NEXT_PUBLIC_OPENWEATHER_API_KEY=your_production_api_key_here
```

### OpenWeather API Setup

1. **Create Account**: https://openweathermap.org/api
2. **Get API Key**: Dashboard → API keys
3. **Free Tier**: 1,000 calls/day, 60 calls/minute
4. **Activation**: Wait 10 minutes after creation

### API Usage Optimization

**Expected API Calls**:
- Without cache: 1 call per LMRA Step 3 load
- With cache: ~1 call per location per hour
- **Savings**: ~95% reduction in API calls

**Cache Strategy**:
- Client-side: 1-hour TTL (localStorage)
- Server-side: 5-minute TTL (in-memory)
- Location-based keys: `weather_{lat}_{lon}`

## 📚 Usage Examples

### Basic Weather Fetch
```typescript
import { getWeatherService } from "@/lib/weatherService";

const weatherService = getWeatherService();
const weather = await weatherService.getWeatherWithCache(52.0907, 5.1214);
console.log(weather.temperatureC); // 20.5
```

### Safety Check
```typescript
const { safe, warnings, blocking, blockingReasons } = 
  weatherService.isSafeForWork(weather, undefined, "height");

if (blocking) {
  console.log("Work must stop:", blockingReasons);
} else if (!safe) {
  console.log("Caution required:", warnings);
}
```

### Display Weather

import { WeatherDisplay } from "@/components/weather/WeatherDisplay";

  compact={false}
/>

## 📞 Support & Troubleshooting

### Common Issues

#### "OpenWeather API key not configured"
**Solution**: 
1. Check `.env.local` exists in `web/` directory
2. Verify variable name is `NEXT_PUBLIC_OPENWEATHER_API_KEY`
3. Restart Next.js dev server
4. Check browser console: `console.log(process.env.NEXT_PUBLIC_OPENWEATHER_API_KEY)`

#### "Weather API error: 401 Unauthorized"
**Solution**:
1. Verify API key is correct
2. Check API key is activated (wait 10 minutes)
3. Ensure no extra spaces in `.env.local`

#### "Weather API error: 429 Too Many Requests"
**Solution**:
1. Exceeded free tier limit (60/min or 1000/day)
2. Wait for rate limit reset
3. Check caching is working
4. Consider upgrading to paid tier
